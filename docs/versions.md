### 1.3.0

> **🎉 新增功能**

| 注解名 | 说明 |
|--------|------|
| `@CEmail` | 新增邮箱格式校验，支持 `allowNull`、域名黑白名单及最大域名层级限制 |

`@CEmail` 的域名名单忽略大小写，并同时匹配指定域名及其所有子域名；支持 17 个 i18n 消息文件，并根据格式错误、黑名单、白名单和层级限制返回对应提示。

> **🔄 功能增强**

| 功能 | 更新说明 |
|------|----------|
| `@CIdCard` | 新增 CN/US/JP/KR/UK 地区规则和自定义 `regexp`；CN 规则仅支持 18 位格式，并允许末位 `X/x` |
| 地区校验 | `@CPhone`、`@CPassport`、`@CPostCode` 和 `@CIdCard` 的 `region` 忽略大小写与首尾空格；多国格式规则与测试样例保持一致 |
| 配置校验 | 未配置自定义正则时，未知 `region` 将抛出 `ConstraintDeclarationException`，不再静默放行 |

> **🐞 Bug 修复**

| 功能 | 修复说明 |
|------|----------|
| `@CIpv6` | 改为纯 IPv6 字面量解析，不再通过 DNS 解析主机名，避免网络依赖和域名误判 |
| `@CDateRange` | 修复精确 `max` 时间被补到当天结束的问题；只有纯日期上限会补全为当天结束时间 |
| `@CFile` | 修复不存在的文件被当作空值放行的问题；不存在的路径和目录现在均校验失败 |
| `@CMoney` | 修复空字符串未按 `allowNull` 配置处理的问题 |
| `@CIdCard` | 修复中国 18 位身份证末位 `X/x` 无法通过的问题 |
| 多国格式 | 修复并调整手机号、护照号、邮编和身份号码的 CN/US/JP/KR/UK 格式规则 |

> **🛠 构建与测试**

* 🧪 接入 JUnit 4 自动化测试，`mvn test` 会实际执行基础、高级、地区矩阵、IPv6 和邮箱校验测试
* ✅ 基础与高级套件覆盖 446 个内部检查，地区格式矩阵覆盖 120 个场景
* 📌 固定 `maven-compiler-plugin` 版本为 3.13.0，提高构建稳定性

> **⚠️ 兼容性说明**

* `@CIdCard(region = "CN")` 不再接受旧版 15 位中国身份证号，仅校验 18 位格式
